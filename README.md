A client-side AI-powered resume analyzer. Upload your PDF and get an instant score, skills analysis, ATS compatibility check, and a personalised improvement roadmap — all running in your browser with no backend required.

Features

Resume score out of 100 with full breakdown
Detects 50+ skills across 8 categories
ATS compatibility check (12-point checklist)
Section detection — Education, Experience, Skills, Projects, and more
Skills gap analysis based on your domain
Keyword density, writing signals, and quick wins
Full improvement roadmap personalised to your resume
100% private — nothing leaves your browser

Tech Stack
HTML · CSS · Vanilla JavaScript · PDF.js · Canvas API  
Upgrade Path
The analyzeResume() function in script.js is structured to be replaced with a real AI API call (OpenAI, Gemini, or Claude) without changing anything else in the codebase.
